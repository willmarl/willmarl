# hai

I like making webui's. heavy obsidian note taker. self host _connoisseur_ on most days. daily drive debian.

## projects

Most of these started as things I wanted but couldn't find.

**[Monno](https://github.com/willmarl/monno)** — NestJS + Next.js monorepo boilerplate. The base every new project starts from. Instructions for AI to make new resource. Auth philosophy: old school where just username and password, email optional.

**[Invare](https://invare.app)** — hardware inventory tracker for arduino parts. kept buying parts i already had.

**[DECT](https://github.com/willmarl/dect)** — gradio + LLM that turns requirement PDFs into test cases (equivalence partitioning, BVA, the whole thing). No more writing tests

**[ezcomfypick](https://github.com/willmarl/ezcomfypick)** — swipe UI for sorting ComfyUI outputs from your phone, comfortabley filter out trash generations. Homelab tool.
